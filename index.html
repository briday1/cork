 BOARD GUIDE

Using Cork

Choose a category from the sidebar, then click the board to place a note. Enter your text in the note.

Move and zoom

Move notes using their top edge. Shift-click to select multiple items, or use the Select tool beside the hand tool to click items or drag a box. Drag the group to move it; Delete removes the selection, and Undo restores it. Hold Space to pan without clearing the group. Scroll or pinch to zoom.

Resize and edit

Notes grow as you type. Drag either lower corner to resize, or the bottom edge to change height. Use the list button for bullets; Enter continues a list and an empty bullet ends it.

Random categories

“Random category” picks from all categories, including categories already on your board. Press R for a random note, I for an index card, or Esc to cancel.

Export and backups

Every board tab saves in this browser on this device. Use Save to write changes to its file. Use Push pins to place a pin on the board or attach one to an item. Select a pin and drag its round handle to resize and rotate it; use String to connect pins or items. Use Images to add a Polaroid. Click the photo to open the original; type a caption below it. Folder adds a local folder link and opens the system folder dialog when clicked. Export PDF saves a tightly cropped copy without cork or controls. Use New board (+) or Import board in the sidebar to open separate tabs. Export board downloads a portable board file, including images, that you can import later. Each tab remembers its own board file. Categories are shared across your account’s boards. Save (Ctrl/Cmd+S) writes the current board file; Save as chooses another file. In browsers without file linking, Save downloads a copy.

Use Edit beside Categories to update the list; changes save automatically. Expand the filename to import or download a text file. Connecting Google Drive keeps one categories text file for your Google account, shared across all boards. Board edits autosave after a board’s first Drive save. Cached boards and categories stay available offline and resume saving after reconnecting. Open Text style for separate heading and body fonts, sizes, and weights; apply them to New notes or Selected notes. Prefix a category with * for Frequently used. Categories missing from the file stay usable under Also on this board. The repository list is only the default. Connecting Google Drive also syncs your account’s categories. Local folder contents are never uploaded.
