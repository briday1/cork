# Assets

## Real cork photograph

`cork.webp` is an optimized copy of the real cork / notice board photograph [PxHere photo 628597](https://pxhere.com/en/photo/628597). The source lists Nikon D5100 camera metadata and dedicates the photograph to the [Creative Commons CC0 1.0 public domain](https://creativecommons.org/publicdomain/zero/1.0/).

Original: 4928 × 3264 JPEG. Bundled web asset: 3072 × 2035 WebP, quality 84, with metadata removed. It is served locally as part of Cork. Pale and dark appearances apply CSS color adjustments to the same photo.

## Cursors

`grab.svg` and `grabbing.svg` are original vector cursor artwork. The SVG sources are accompanied by 2× and 3× PNG renderings selected with CSS image-set so high-density displays do not upscale a small cursor bitmap. CSS supplies the platform hand cursor as a fallback.
